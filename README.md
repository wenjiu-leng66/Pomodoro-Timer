# Pomodoro-Timer
本项目为基于 Electron 33 框架构建的桌面端专注工作计时器（番茄钟）

## 功能定位

应用界面采用双栏布局：左侧为带进度圆环的计时模块，右侧为任务列表与统计模块。

- **计时机制**：采用标准番茄工作法，默认专注时长 25 分钟、短休 5 分钟，每完成 4 个专注周期进入 15 分钟长休，随后重新循环。各阶段时长及长休间隔均可于设置面板中调整。

- **自动流转**：专注阶段结束后自动发送系统通知并记录完成番茄数，归入当前任务；休息阶段结束后自动进入下一专注周期，全程无需人工干预。

- **任务管理**：支持任务清单的增删，每项任务累计关联的番茄数。

- **数据统计**：每次完成的专注均写入历史记录，支持按 "今日 / 本周" 两个时间维度进行统计。

- **托盘驻留**：关闭主窗口不退出程序，转入系统托盘后台继续计时，可通过托盘菜单唤回窗口或退出应用。

## 技术架构

- **状态机设计**：计时核心模块以 `IDLE → RUNNING → PAUSED → FINISHED` 四态管理运行状态，各阶段在专注 / 短休 / 长休之间循环轮转，逻辑独立封装，界面事件由应用入口模块统一协调。
- **数据持久化**：设置、任务、历史记录均通过 `electron-store` 持久化至本地 JSON 文件；渲染进程经 `preload.js` 暴露的 API 走 IPC 通道读写数据，并启用了 `contextIsolation` 隔离、禁用 `nodeIntegration`，安全配置规范。
- **交互细节**：支持空格键快速开始 / 暂停，进度圆环随剩余时间实时收缩，剩余时间同步显示于窗口标题栏。
- **通知机制**：专注 / 休息切换调用系统级 Notification，点击通知可唤回主窗口。
